# 要打去練舞室打

雙人鍵盤音樂遊戲。純 HTML / CSS / JavaScript，不用安裝任何東西。

## 怎麼開

1. 用 VS Code 開這個資料夾
2. 安裝擴充功能 **Live Server**
3. 在 `index.html` 上按右鍵 → **Open with Live Server**

（拍照頁要用鏡頭，一定要用 Live Server 開；直接點兩下 `index.html` 鏡頭可能會被瀏覽器擋掉。）

玩的時候記得把輸入法切成**英文**，不然 W A S D 會被注音吃掉。

## 畫面流程

| 編號 | 畫面 | 名稱（程式裡用的） | 按鍵 |
|---|---|---|---|
| 0.0 | 首頁 | `home` | 空白鍵開始、D 死語詞典 |
| 0.1 | 死語詞典 | `dictionary` | ▲▼ 滑動、ESC 回首頁 |
| 1.0 | 引言 | `intro` | 空白鍵繼續 |
| 2.0 | 拍照 | `photo` | 空白鍵開始倒數，之後自動 |
| 2.1 | 建模動畫 | `model` | 空白鍵下一步 |
| 3.0 | 舞台選擇 | `stage` | ▲▼ 選、空白鍵決定 |
| 4.0 | 音樂選擇 | `music` | ▲▼ 選、空白鍵決定 |
| – | Loading | `loading` | 自動 |
| 5.0 | 對戰 | `battle` | P1：W A S D　P2：方向鍵 |
| 6.0 | 結算 | `result` | 空白鍵回首頁 |

**開發小技巧**：網址後面加 `#名稱` 可以直接跳到那一頁，例如 `index.html#battle`。

## 檔案放哪裡

```
index.html            所有畫面的 HTML（每個 <section> 是一個畫面）
css/
  base.css            顏色、字體變數、共用元件（提示字、玩家標籤、小人）
  screens.css         每個畫面各自的版面
js/
  data.js             ★ 內容：死語、引言文字、舞台清單、歌曲清單
  state.js            跨畫面要記住的資料（照片、選的舞台和歌、成績）
  router.js           換頁 goTo() 與鍵盤分配
  main.js             啟動、畫布縮放
  lib/cutout.js       自動去背、偵測五官、把照片切成頭和身體的貼圖（眼睛放大改最上面的 FACE）
  lib/lowpoly.js      低面數 3D 小人（比例改最上面的 BODY，舞步改 DANCE_MOVES）
  screens/            每個畫面一個檔案
assets/
  images/             bg.jpg（共用背景）、title.png（主視覺字）、deco.png（首頁裝飾）
  audio/              音樂檔放這裡
```

## 常見的修改

- **改文字、加死語、加舞台、加歌** → `js/data.js`
- **改顏色、字級** → `css/base.css` 最上面的 `:root`
- **改某一頁的排版** → `css/screens.css` 找那一頁的區塊
- **改某一頁的行為** → `js/screens/那一頁.js`

畫布固定是 1920×1080（跟 AI 檔一樣），會自動縮放到視窗大小，所以排版直接用 px。

## 3D 小人和去背

- 拍完照會自動去背、偵測五官：用臉的位置框出頭（臉一定在正中間）、把眼睛放大，再貼到低面數小人上；手腳的顏色取自衣服和膚色。
- 眼睛放大幾倍、頭髮留多少，改 `js/lib/cutout.js` 最上面的 `FACE`。
- 去背和五官偵測用 Google MediaPipe，**要連網路**下載模型。沒網路或找不到臉時會改用固定的人形輪廓去切、眼睛不放大，流程照樣能走完，只是沒那麼準。
- 還沒拍照就直接跳到後面的頁面（例如 `#battle`）時，小人會用替代的臉。
